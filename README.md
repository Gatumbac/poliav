# poliav

Tools to use ESPOL's Aula Virtual from the terminal and from an AI agent. It includes a Canvas API client that renews its own tokens, a CLI, and tools for the nand harness. This is an unofficial project.

## Status

Early development. Built for the CIAP club at ESPOL. It is not affiliated with Instructure or ESPOL.
